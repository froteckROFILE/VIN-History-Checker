# VIN History Checker

Clean Android Java project (no Kotlin plugin, no Gradle wrapper required).

## Features
- VIN decoding through official NHTSA vPIC
- Manufacturer, model, model year, engine and displacement
- Links to external auction, recall and theft resources
- PDF report saved in app documents folder

## Build
GitHub Actions > Build Android APK > latest successful run > Artifacts > VIN-History-Checker-APK.

This app does not provide a verified CARFAX, accident, ownership, odometer or auction history without commercial data integrations.
